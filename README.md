# Employee & Branch Performance Analytics

A Power BI dashboard developed to analyze **employee and branch performance** using key performance indicators and interactive visualizations.

## 📊 Project Overview

This dashboard provides a consolidated view of employee and branch performance, helping compare performance across different branches and employees.

## 🛠️ Tools Used

* **Power BI**
* **Microsoft Excel**
* **Power Query**
* **DAX**

## 📈 Dashboard Highlights

* Branch-wise performance analysis
* Employee-wise performance analysis
* KPI-based performance tracking
* Performance comparison across branches and employees
* Interactive filters and visualizations
* Summary metrics for business performance monitoring

## 🎯 Objective

The objective of this dashboard is to provide a clear and interactive view of employee and branch performance to support performance monitoring and data-driven decision-making.

## 🔒 Data Disclaimer

This project was developed using company data. **Raw source data and confidential employee information are not included in this repository.**

The dashboard is shared for portfolio and demonstration purposes only.
